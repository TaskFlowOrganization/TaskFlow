# TaskFlow

TaskFlow is a RESTful API for task management built with Spring Boot using a layered architecture approach.

---

## Features

- Create a task
- Get a task by ID
- Get all tasks
- Update a task
- Delete a task
- Global exception handling
- Unified JSON error responses

---

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
- Lombok
